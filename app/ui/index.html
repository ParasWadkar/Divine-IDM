Queues

A queue runs a few of its downloads at a time and holds the rest back. Switching one off stops it starting anything more; whatever it already has running carries on, because stopping a transfer mid-flight is what Pause is for.

Schedule

Slow downloads down, or stop them altogether, at times you choose. While a rule is in force it decides the speed, instead of the limit in Settings — so you can hold downloads back during the day and let them run at full speed overnight. Where two rules overlap, the stricter one wins.

Saved passwords

Kept in Windows' own Credential Manager, not in this app's files — so you can see and delete them in Control Panel even if DivinePulse is not running. Nothing here is ever shown back to you, including to this window.

Video tools

Some video arrives as separate picture and sound tracks. Joining them needs ffmpeg, which is not included because it is larger than the rest of this app put together. A copy already on your PATH is used as it stands. One fetched here is checked against the exact build DivinePulse pins — when it arrives, and again every time before it runs.

Browser integration

Your browsers
Need to install manually?

DivinePulse is already registered with your browsers. The extension itself has to be added by hand, because it is not in any web store and a browser will only load one from its own developer page.

  1. Open chrome://extensions — or about:debugging in Firefox.
  2. Turn on Developer mode.
  3. Choose Load unpacked and pick the folder below. In Firefox it is Load Temporary Add-on, and you pick manifest.json inside it.
