Install the extension

Divine IDM is already registered with your browsers. The extension itself has to be added by hand, because it is not in any web store and a browser will only load one from its own developer page.

  1. Open chrome://extensions — or about:debugging in Firefox.
  2. Turn on Developer mode.
  3. Choose Load unpacked and pick the folder below. In Firefox it is Load Temporary Add-on, and you pick manifest.json inside it.
